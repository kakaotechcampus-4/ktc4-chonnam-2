# archive

과거 제출물, 발표자료, 이전 구조처럼 **현재 living document의 Source of Truth가 아닌 snapshot**을 보관한다.

- archive 문서는 현재 제품/아키텍처/역할 결정을 덮어쓰지 않는다.
- 과거 맥락·발표 스토리를 확인할 때만 참고한다.
- 현재 결정이 필요하면 living docs에 반영한다.

## 하위 폴더

- `ktc/` — Kakao Tech Campus 제출·심사용 snapshot (서비스 기획안 1.3 · 발표 노트)
- `management/` — 결정 완료로 닫힌 회의 안건지. 결정 자체는 `docs/management/cross-cutting-decisions.md`에 있다
