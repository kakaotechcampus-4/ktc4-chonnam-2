# Evidence Rule / 신고요건 변경에 별도 서명자를 두지 않는다

> 결정일 2026-09-04 · 근거 `management/cross-cutting-decisions.md` B-3

## 결정

1.3의 「서명자 지정」(Evidence Rule / 신고요건 변경 = 평가·QA 담당자)을 두지 않는다. `evidence` Owner가 구현과 승인을 겸한다.

## 이유

- `evidence`는 아무도 호출하지 않는 순수 함수 모듈이라 규칙 변경이 테스트로 즉시 검증된다.
- 6인 팀에 별도 검토자를 뺄 여유가 없다.

## 대신 지키는 것

- **신고요건 규칙(기한·용량·필수 항목·유형 매핑)이 바뀌면 주간 회의에 보고한다.** 챌린저 개방(A-2)과 같은 리듬이다.
- Tool Trajectory 판정(`management/tool-trajectory-review.md`)은 `case` Owner가 맡는다. 규칙을 만든 사람이 아닌 사람이 규칙 통과를 판정하는 구조는 거기서 회복된다.

## 왜 기록을 남기나

1.3이 분리를 둔 이유는 「신고요건 규칙은 틀리면 사용자가 실제로 반려당하는 출력」이기 때문이다. 조용히 사라지면 나중에 「왜 검토자가 없지?」가 된다. 겸했다는 사실과 이유를 여기 남긴다.
