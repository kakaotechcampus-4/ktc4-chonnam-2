# 2026·2027 대한민국 공휴일 snapshot 조사

> 상태: **VERIFIED — 2026-09-13**
>
> 범위: 안전신문고 교통법규 위반 신고기한 계산에 사용할 대한민국 전국 단위 공휴일

## 1. 결론

- 채택된 Owner 결정은 [ADR-EVIDENCE-002 K2](../adr/adr-first-completion-owner-decisions.md)가 authoritative하다.
- Runtime은 외부 공휴일 API를 호출하지 않고 [`deadline_policy_v1.json`](../../../../src/daesingo/evidence/deadline_policy_v1.json)을 사용한다.
- snapshot은 2026년 22일, 2027년 24일이며 날짜별 공식 근거 식별자는 JSON의 `source_ids`에 보존한다.
- 이 문서는 근거 요약이다. 동일 JSON 전문을 중복 수록하지 않는다.

## 2. 채택 이유와 보정 사항

- 2025-06-30 발표된 2026년 월력요항은 당시 법령 기준 공휴일 20일을 제시했다. 이후 2026년 법 개정으로 노동절과 제헌절이 공휴일이 되고 두 날에도 대체공휴일이 적용되므로, 기존 월력요항만 복사하지 않고 최신 법령·인사혁신처 자료로 보정했다.
- 2026-06-03 제9회 전국동시지방선거는 공휴일로 지정되는 선거일이므로 포함했다.
- 2027년 목록은 2026-06-29 발표된 2027년 월력요항과 최신 법령을 교차 확인했다.
- 현충일에는 대체공휴일을 만들지 않았다. 설날·추석은 토요일과 겹쳤다는 이유만으로 대체공휴일을 추가하지 않고, 일요일 또는 다른 공휴일과 겹치는 경우에만 관련 규정을 적용했다.
- 지방공휴일은 전국 단위 신고기한 정책에 직접 적용된다는 근거가 없어 제외했다.
