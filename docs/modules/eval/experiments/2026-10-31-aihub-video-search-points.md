# 2026-10-31 · AIHub 선별 영상과 블박 삽입 세트의 S1·S2·S3 비교

Search 시점별 설정을 **같은 신규 입력**에 적용한 개발 평가다. [10/28 시점별 평가](2026-10-28-search-points-pipeline.md)의 S1 Flash 1배속, S2 Flash 느린 영상, S3 argon 설정을 현재 Search 코드에서 재구성했다. 당시 코드 전체를 재실행한 것이 아니라 모델·배속·Fine 프롬프트 분기부·단가만 시점별로 바꾼 비교다. 실제 장시간 블랙박스의 잠근 평가 결과가 아니다.

## 1. AIHub 단독 영상: 영상 단위 최상위 후보 유형

`a_aihub_best100_all`은 AIHub 선별 영상 400개(4종별 100개, 원본 Training 271개 포함)다. `a_aihub_best100_val`은 이 중 원본 Validation이며 기존 A tier와 시퀀스 중복을 제거한 117개다(신호 37·중앙선 36·실선 35·안전모 9). S1·S2·S3 각각 전체 400개를 **한 번씩** Coarse로 실행하고, 동일 실행의 예측에서 117개를 추출해 비교했다. 최상위 후보의 유형이 원본 영상의 유형 라벨과 같으면 적중이다. 모두 양성 영상이고 정확한 위반 발생 시점 정답은 없다.

| 입력 | S1 Flash 1배속 | S2 Flash 느린 영상 | S3 argon |
| --- | ---: | ---: | ---: |
| 전체 400개 유형 적중 | 355/400 (88.8%) | 360/400 (90.0%) | 371/400 (92.8%) |
| 중복 제거 Validation 117개 유형 적중 | 100/117 (85.5%) | 102/117 (87.2%) | 105/117 (89.7%) |
| 전체 400개 비용 기록 | $0.68 | $0.82 | $2.43 |

Validation 117개 적중률의 95% Wilson 구간은 S1 **78.0–90.7%**, S2 **79.9–92.1%**, S3 **82.9–94.0%**로 서로 겹친다. 같은 영상에서 S3의 총 적중이 가장 많지만 작은 차이를 확정적 우위로 해석하지 않는다.

| Validation 유형 | 분모 | S1 적중 | S2 적중 | S3 적중 |
| --- | ---: | ---: | ---: | ---: |
| 신호 위반 | 37 | 30 | 29 | 35 |
| 중앙선 침범 | 36 | 30 | 29 | 30 |
| 실선 차로 변경 | 35 | 31 | 35 | 31 |
| 안전모 미착용 | 9 | 9 | 9 | 9 |

세 실행 모두 400/400 `SUCCEEDED`였다. S3의 400개 실행은 10/30에 완료된 결과를 재사용했다. [10/30 보고서](2026-10-30-aihub-best100-video-and-mixed.md)의 Validation 117개 *별도 호출*도 105/117이지만, 개별 예측 5개는 전체 400개 실행과 달랐다. 위 표는 시점 간 입력·호출 단위를 맞추기 위해 **전체 실행에서 추출한 117개**를 쓴다. 117개는 최종 locked test가 아니며, 영상의 10fps는 JPEG 시퀀스 재생용이라 실제 촬영 시간을 뜻하지 않는다. 정상 영상이 없어 특이도·오탐률은 이 표에서 계산하지 않는다.

## 2. 실제 블박 사이 AIHub 삽입: 합성 탐색 진단

`aihub_mixed_100_v1`은 검토된 서로 다른 정상 블박 배경 100개에 AIHub 영상 100개(4종별 25개)를 끼워 넣은 **삽입 100개**와 같은 배경을 재인코딩한 **정상 대조 100개**다. 삽입 원본은 Validation 84개·Training 16개이며 삽입 시작은 10·20·30초를 순환한다. 상위 3개 후보의 대표 시점이 **삽입된 장면 전체 구간** 안에 있으면 위치 일치, 유형까지 맞으면 유형 일치, 해당 후보의 Fine 결과가 `OBSERVED`면 검증 일치로 센다. 이는 사건 onset ±2초 Recall이 아니다.

### 100쌍 혼합 영상 결과

같은 200개 영상에 각 시점의 Coarse와 Fine을 함께 적용했다. 실패와 부분 실패도 분모에 남겼다. `OBSERVED`는 Fine이 해당 후보에서 위반을 관찰했다고 반환한 상태이며, 정상 대조에서는 최종 오탐 후보로 센다.

| 지표 | S1 Flash 1배속 | S2 Flash 느린 영상 | S3 argon |
| --- | ---: | ---: | ---: |
| 삽입 100개: Top-3 위치 일치 | 96 | 89 | 97 |
| 삽입 100개: 위치·유형 일치 | 88 | 77 | 89 |
| 삽입 100개: 위치·유형·Fine `OBSERVED` | 45 | 37 | 78 |
| 정상 대조 100개: 후보가 나온 영상 | 77 | 70 | 72 |
| 정상 대조 100개: `OBSERVED` 후보가 나온 영상 | **8** | **9** | **29** |
| 정상 대조의 `OBSERVED` 후보 총수 | 9 | 10 | 40 |
| 200개 처리 상태: 성공/부분 실패/실패 | 198/2/0 | 172/21/7 | 191/9/0 |
| `COARSE_SPAN_OUT_OF_SOURCE` 발생 영상 | 2 | 28 | 9 |
| 후보별 Fine 오류 | 5 | 11 | 2 |
| 기록된 모델 호출 비용 | $2.09 | $3.15 | $9.03 |

S3는 삽입 구간의 Fine 확인 78/100으로 S1의 45/100, S2의 37/100보다 높았다. 동시에 정상 대조에서 `OBSERVED`가 나온 영상은 S1 8/100, S2 9/100, S3 29/100이었다. 따라서 회수 성능만 보고 S3를 전반적으로 우수하다고 말할 수 없다. S2는 구간 밖 후보가 28개 영상에서 발생했고 7개 실행이 실패했다. 이 실패도 100개 분모에서 제외하지 않았다. 원인 분리를 위한 별도 모델·프롬프트 실험은 이번 비교에 포함되지 않는다.

| 삽입 사건 유형 (각 25개) | S1 위치/유형/확인 | S2 위치/유형/확인 | S3 위치/유형/확인 |
| --- | ---: | ---: | ---: |
| 중앙선 침범 | 24/23/15 | 23/20/9 | 24/21/19 |
| 안전모 미착용 | 25/24/7 | 25/23/14 | 24/21/21 |
| 신호 위반 | 23/18/10 | 19/13/7 | 24/22/20 |
| 실선 차로 변경 | 24/23/13 | 22/21/7 | 25/25/18 |

이 혼합 영상은 전체 AIHub 장면을 블랙박스 영상에 삽입하고 두 구간을 재인코딩했다. 장면·화질·시간축의 접합부가 단서가 될 수 있다. 원본 100개 중 84개는 Validation, 16개는 Training 출처이며 독립 잠금 test가 아니다. 따라서 이 값은 합성 입력에서의 개발 진단이고, 실제 연속 주행 영상의 시간 정확도나 일반적 탐지율은 아직 측정하지 않았다. 정상 대조 100개도 검토된 음성 샘플이지만 전체 도로 상황의 오탐률을 대표하지 않는다.

## 3. 재현과 원본 결과

```bash
uv run python -m eval.tools.evaluate_aihub_best100 run --set all --point s1 --run-id <새_id>
uv run python -m eval.tools.evaluate_aihub_best100 run --set all --point s2 --run-id <새_id>
uv run python -m eval.tools.evaluate_aihub_best100 derive-val --from-run-id <전체_run_id> --run-id <새_val_id>
uv run python -m eval.score --prediction <전체_또는_val_run_id>
uv run python -m eval.tools.evaluate_aihub_mixed run --dataset aihub_mixed_100_v1 --point s1 --fine --run-id <새_id>
uv run python -m eval.tools.evaluate_aihub_mixed run --dataset aihub_mixed_100_v1 --point s2 --fine --run-id <새_id>
```

영상 원본·합성 MP4는 로컬에만 두고 `eval/manifests/a_aihub_best100_{all,val}/`, `eval/manifests/aihub_mixed_100_v1/`에 목록과 해시를 기록했다. 예측과 채점 JSON은 `eval/predictions/`·`eval/results/`의 `aihub_best100_*_s{1,2,3}_*` 및 `aihub_mixed_100_v1_s{1,2,3}_fine_*`에서 확인한다.
