### 안전모 미착용 — 별도 정리

**구조**: `머리` bbox + `이륜차` bbox 두 개가 쌍으로 라벨링. 착용/미착용이 클래스명에 인코딩.

**좋은 점 3개**
1. **4종 중 유일하게 시간 순서 불필요** — 객체 속성이므로 frame 단위로 위반 자체를 채점할 수 있는 유일한 종
2. **hn이 데이터 안에 있음** — 착용:미착용 약 1:4.5. 분포 안에서 나온 hn이라 인공 hn보다 질이 좋음
3. 그래서 **파이프라인 배관 검증(runner→scorer→results)의 파일럿 후보로 최적**

**문제 3개**
1. **규모** — event 약 580건. 4종 중 압도적으로 적다. macro 평균에서 이 종의 신뢰구간이 다른 종의 5~6배
2. **R-M 연결이 명시적이지 않음** — RideSafe-400은 `R-M instance` 명시 링크가 있지만 여기는 `머리`·`이륜차` bbox만 있고 「이 머리가 이 이륜차의 것」이라는 연결 정보가 없다. 포함관계/IoU로 추정해야 하고, 추정 오류가 `TARGET_ASSOCIATION` 채점 오류로 위장된다
3. **번호판 — 제품 차원 이슈.** 이 데이터에 번호판 클래스가 없다. 그리고 **한국 이륜차는 후면에만 번호판을 부착한다.** 앞서가는 이륜차는 후면이 보여 판독 가능하지만 **마주오는 이륜차는 구조적으로 판독 불가**다. 즉 안전모 미착용은 **촬영 기하에 따라 신고 가능 여부가 갈린다.** eval 문제가 아니라 기획 확인 사항이며, 제품이 마주오는 이륜차도 후보로 올린다면 `readout`은 필연적으로 abstain하고 그건 오탐이 아니라 **정상 동작으로 채점**해야 한다.

**결론**: 안전모는 frame suite에서 위반 자체를 채점할 수 있는 유일한 종이지만, 규모(580건)와 번호판 구조 때문에 **4종 macro 평균에 그냥 넣으면 안 된다.** 안전모 제외 3종 macro를 주 지표로, 안전모는 별도 표기가 맞다.

## 6. 원문 — 이미지냐 영상이냐

**먼저 물을 것.** 「영상으로 만들까」가 아니라 **`search`의 공개 함수가 소비하는 단위가 무엇인가**다. `recording`이 프레임을 공급한다면 **mp4로 인코딩할 필요가 아예 없다.**

| | 방식 | 판정 | 근거 |
| --- | --- | --- | --- |
| **A** | 프레임 그대로 → `frame/` suite | **채택** | PRIMITIVE 관찰·hn·안전모 진단용 |
| **B** | 시퀀스 순서대로 → `clip/` suite | **채택(조건부)** | 순서 O, **속도는 우리가 발명** |
| **C** | clip을 이어붙여 long video | **dev 전용** | 최종 주장은 real에서만 |
| **D** | 프레임을 임의 fps로 슬라이드쇼 인코딩 | **금지** | 아래 |

**B의 조건 — fps가 없다.** `Basic File Date and Time`이 `20230222`로 날짜뿐이라 프레임 간 간격을 알 방법이 데이터에 없다. 결과: `TEMPORAL_ORDER` 채점은 **열림**(순서만 필요), `timestamp error`는 **닫힘**(초 단위 필요). **clip suite에서 시간·속도 관련 지표 전면 금지, 순서만 채점.** `timestamp error`는 **팀원 실촬영에서만 측정 가능한 유일한 지표**가 된다.

**D를 금지하는 이유.** 프레임 간격을 우리가 정하면 화면상 움직임 속도가 물리적으로 임의값이 된다. 4종 중 셋이 시간 순서로 정의되는데, 그 시간을 발명한 상태의 `timestamp error`·`FP/hour`는 제품 성능과 인과가 없다.

**성능 주장 범위**

| suite | 발표 가능 | 지표 |
| --- | --- | --- |
| `frame/` | 불가(진단만) | `primitive_acc`, `hn_fpr` (Precision·Recall 단어 금지) |
| `clip/` | 순서만 | `temporal_order_acc`, `fine_fn` |
| `long/` real | 가능 | `Recall@K`, `FP/hour`, `timestamp error` |
| `long/` synth | 불가(상대비교만) | impl A vs B, 회귀 감지 |

`frame/` 숫자를 제품 성능으로 발표하면 안 되는 이유는 base rate 함정이다. TPR .9 / FPR .1인 동일 모델이 사전확률 0.5에서 PPV .90, 0.001에서 PPV .009로 100배 차이가 난다. `frame/`의 사전확률은 폴더 구성으로 정해지는 인공 값이다.

`LANE_CHANGE` → **`SOLID_LINE_LANE_CHANGE`**. baseline enum은 `module-architecture.md` §3-5의 4종(사본 `eval/enums.py`)이다. 원문 이름으로 쓰면 5×5 혼동행렬이 조용히 어긋난다. §5 표에 병기해 두었다.

### 7-2. 「채점 단위 시퀀스 44,976건」 → 실제 표본은 120건

현행 A tier는 전수가 아니라 **종별 층화 표본**이다 — 종당 30 시퀀스, seed `20260906`, 규칙 `s1`(`eval/manifests/a_aihub/sequences.json`). 정답지 `g1`은 120건이고 `target_bbox`가 있는 항목은 115건이다. split은 현재 전부 `DEV`이며 `locked`는 아직 없다. 즉 §3의 44,976건은 **모집단 규모**이고 채점 표본이 아니다.

### 7-3. 「안전모 제외 3종 macro를 주 지표로」 → 미채택(보류)

현행 `eval/scorers/classification.py`는 4종 + `NONE`의 5×5를 그대로 쓰고 `recall_macro`·`precision_macro`를 4종 전체로 낸다. 표본이 종당 30으로 균등해 원문이 걱정한 규모 편차(580 vs 19,700)가 표본 단계에서는 드러나지 않기 때문이다. **전수로 확장하면 원문 결론이 다시 유효해진다.**

### 7-4. 메타 필드 신뢰 등급 — 준수 확인

`g1`은 `Resolution`·`MAGNITUDE`를 싣지 않는다. 싣는 것은 `condition{weather, day_night, road_type}`·`target_bbox`·`target_frame`·`distractor_count`·`source_tier`뿐이다.

### 7-5. §6의 「search가 프레임인가 mp4인가」 → 해소

`search`는 파일 경로를 받지 않는다. `AnalysisRun.input_ref`는 Coarse에서 `{kind: ANALYSIS_SCOPE}`, Fine에서 `{kind: analysis_source}`이고(`contract-analysis-run-candidate-event.md` §3-1·§4-1), 자산 계층은 `recording`이 추상화한다(v4 §3-3 「search는 파일을 생성하지 않는다」). **mp4 인코딩 논의는 불필요**하고, 원문 D(임의 fps 인코딩) 금지 결론도 그대로 유효하다.

### 7-6. 여전히 미결

| 원문 항목 | 현재 |
| --- | --- |
| 프레임 간격(fps) | **미결.** manifest·정답지 어디에도 프레임 간격이 없다. A tier에서 onset/timestamp 지표는 계속 닫힘 |
| 라이선스 4개 | **미결.** 다만 운용은 이미 보수적으로 잡혀 있다 — 미디어는 커밋하지 않고(`eval/datasets/README.md`, 루트 `.gitignore`) manifest + `sha256`만 커밋한다. 질문 3(정답지에 파일명·bbox 포함)은 **현재 포함해 운용 중**이라 확인 결과에 따라 되돌려야 할 수 있다 |
| 라벨 노이즈율 전수 측정 | **미결.** 표본에서 발견된 `_0000000003`(폴더는 위반인데 위반차량 라벨 0프레임)·`_0000000001`(폴더는 적색인데 플립 프레임 신호등 황색)이 그대로 남아 있고, 현행 `g1`은 폴더 기준 단일 `label`만 싣는다 |
| 안전모 번호판 촬영 기하 정책 | **미결.** `docs/modules/evidence/decisions/safety-report-policy-v1.md`가 신고유형 매핑(`MOTORCYCLE_VIOLATION`)과 「잘 모르겠어요」 fallback까지는 정했지만, 「마주오는 이륜차는 판독 구조적으로 불가 → abstain이 정상 동작」은 어디에도 없다 |
| `case.export_run()` jsonl | **미등재.** 계약·모듈 문서 전체에서 `export_run` 언급 0건. Final Event Recall 측정 경로가 아직 없다 |
