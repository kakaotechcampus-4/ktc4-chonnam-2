## 왜 이 조합인가

- **미세조정 인식기를 넣지 않는다.** 블랙박스 GT 71항목에서 사전학습 19 · 미세조정(노트북 1회차) 22로 격차가 작고, 1회차의 확정 오답은 전부 2줄 윗줄 지역명 지어내기다. 지역명 처리 없이 바꾸면 틀린 지역명을 확정한다. 근거: `../experiments/plate-rec-finetune-2026-09-29/README.md` §3-④ · §5
- **AI Hub로 학습한 가중치를 제품에 넣어도 되는지는 정해지지 않았다**(PM 확인). 그 전에는 넣을 수 없다.
- 사전학습 모델은 설치만으로 재현된다 — 가중치 배포 · checksum 관리가 필요 없다.
- 틀린 번호를 확정하지 않는 쪽을 택한다. 읽지 못하거나 일부만 읽으면 보류하고 사용자가 직접 입력한다(`MANUAL_PLATE_INPUT`).

## 실험 결과와 운영 모델의 구분

`docs/modules/readout/experiments/` 아래 수치는 **실험 기록이지 운영 성능이 아니다.**

| 실험 | 운영에 들어갔나 |
| --- | --- |
| `plate-rec-finetune-2026-09-29` 미세조정 인식기(노트북 1 · 2회차 · 데스크톱 ① · ②) | 아니오. 가중치도 레포에 없다 |
| 같은 실험 §3-⑤ 고시 기반 번호 형식 규칙(`plate_rule.py`) | 아니오. 제품 형식 검사는 위 표의 느슨한 형식이다 |
| 프레임 간 다수결 | 예(#345) |
| `two-line-merge-2026-09-23` 2줄 윗줄 합치기 | 아니오. 운영은 아랫줄만 읽어 보류한다 |

## 정하지 않은 것

- 고시 기반 형식 검사를 제품에 넣을지. 손실 0 · 오답 감소는 확인했다. [미결]
- 2줄 번호판 윗줄 지역명을 어떻게 읽을지(17종 닫힌 분류 · 합성 데이터 등). 읽는 것 자체는 목표로 정해져 있다. [미결]
- 미세조정 인식기로 바꿀지. [미결 — 지역명 처리 · AI Hub 가중치 사용 확인 뒤]
- 운영 판독 성능 수치. 제품 조합으로 잰 최종 수치는 `eval`이 낸다.
