## 0. 한 줄

1. **트랙으로 고르면 처음 보는 표본에서 32.0% → 47.9%** (+15.9%p). 기존 Best Frame 대비다.
2. **그래도 절반이 틀리고, 틀릴 때 78%는 정상 차량을 고른다.** 조용한 오답이라
   `target_association.status`는 계속 `LOW_CONFIDENCE`여야 한다 — `ASSOCIATED`로 올릴 근거가 아니다.
3. **확신도로 거르면 정확도가 오른다.** 모델 확률 ≥ 0.5인 클립만 받으면 holdout 38%를 덮고
   정확도 67.7%. 나머지는 「고르지 못함」으로 둔다.
4. **천장이 81%다.** 트랙 안에 위반 차량이 아예 없는 클립이 19% — 검출기(yolo11n)·트래커 한계이지
   선택 규칙으로는 못 넘는다.

## 1. 무엇을 바꿨나

track1은 프레임마다 박스 하나를 독립으로 골랐다. 여기서는

1. 연속 프레임의 검출을 IoU 0.3 greedy 체이닝으로 이어 **트랙**을 만들고(1프레임 공백 허용)
2. 트랙마다 특징 11종을 뽑아 — 지속 비율 · 평균 conf · 크기 · 화면 중심과의 거리 · 세로 위치 ·
   옆 이동(순이동·누적) · 크기 변화 · 오토바이 여부 · 기존 규칙 득표
3. 클립 안 softmax(conditional logit)로 「이 클립에서 어느 트랙인가」를 학습했다.

연결 파라미터(IoU 0.05~0.5 · 공백 0~3)를 dev에서 훑었지만 CV 차이가 ±2%p(= 1~2클립)라
노이즈로 보고 기본값을 유지했다.

## 2. 과적합을 어떻게 막았나

| | dev | holdout |
| --- | ---: | ---: |
| 출처 | track1 클립 표본 (seed `20260919`) | **새로 뽑음** (seed `20260927`) |
| 클립 (위반 보임 · 트랙 ≥ 1) | 88 | 169 (dev와 겹치는 8클립 제외) |
| 쓰임 | 규칙 설계 · 5-fold CV · 학습 | **dev로 학습한 가중치를 한 번만 적용** |

holdout을 본 뒤 규칙·특징·파라미터를 고치지 않았다.

## 3. 결과

### ① 처음 보는 표본(holdout)에서

| 방법 | 정확도 | 틀릴 때 정상 차량 |
| --- | ---: | ---: |
| 기존 — Best Frame (`aihub71555_clips.py`, 분모 178) | 32.0% | — |
| 고정 규칙 최고 — 옆으로 가장 많이 움직인 트랙 | 37.3% | 77.4% |
| **학습 규칙 (기본 11종)** | **47.9%** (81/169) | 78.4% |
| 학습 규칙 + 상대 특징 5종 (16종) | 42.6% | 75.3% |
| 학습 규칙 − 오토바이 여부 | 42.6% | 80.4% |
| *(천장 — 위반 트랙이 있는 클립)* | 81.1% | |

- 상대 특징(다른 트랙 대비 옆 이동 · 중앙 가로지름 · 클립 내 순위)은 **오히려 떨어졌다.**
  dev 88클립에 특징 16개는 과하다.
- 오토바이 여부를 빼면 5.3%p 떨어진다. 대부분 안전모미착용 클립에서 오는 이득이라,
  **사용자 블랙박스에서 같은 폭으로 재현된다고 가정하지 않는다.**

### ② 확신도로 걸렀을 때 (holdout)

| 모델 확률 ≥ | 덮는 클립 | 정확도 |
| --- | ---: | ---: |
| 0.0 (전부) | 100% | 47.9% |
| 0.4 | 53% | 64.0% |
| **0.5** | **38%** | **67.7%** |
| 0.7 | 19% | 75.0% |

임계값은 **정하지 않는다.** 이 표는 「고르지 못함」으로 돌리는 비율과 정확도의 교환을 보이는
것이고, 몇 %의 오답을 받아들일지는 `evidence`가 `LOW_CONFIDENCE`를 어떻게 다루는지와 같이
정해야 한다(계약 §5).

### ③ 유형별 (holdout, 학습 규칙)

| 대분류 | 클립 | 정확도 | 천장 |
| --- | ---: | ---: | ---: |
| 신호위반 | 61 | 39.3% | 83.6% |
| 안전모미착용 | 23 | 56.5% | 69.6% |
| 중앙선침범 | 42 | 52.4% | 88.1% |
| 진로변경위반 | 43 | 51.2% | 76.7% |

신호위반이 가장 약하다 — 교차로에는 비슷하게 움직이는 차가 많아 움직임 특징이 덜 갈린다.

## 4. 이 결과로 하지 않는 것

- **제품 경로에 붙이지 않는다.** 지금 `PaddleOcrProvider`에는 차량 검출기가 없고, 붙이려면
  `ultralytics`/`torch` 의존성이 들어온다. **`ultralytics`는 AGPL-3.0이다** — 제품 런타임에
  넣을지는 성능이 아니라 라이선스·배포 판단이 먼저다. [미결]
- **`ASSOCIATED`로 올리지 않는다.** 위 ①의 오답 성격 그대로다.
- **임계값을 정하지 않는다.** ②.
