# web 접근성 검사 — 2026-10-31 (W12 W6)

> 검사·기록: 신유민(web Owner). 고치기는 화면 담당(김대원) 몫이라 여기서는 결함과 한계만 남긴다.
> 기준: 팀 접근성 적용안(최종 산출물 레포 `reviews/2026-10-24-accessibility-lecture-application.md`)의 A11Y-01~06과 그 문서 §4 검증 절차. 자동 검사 규칙은 WCAG 2.0/2.1 A·AA, 2.2 AA.
> 대상: develop `d1f57b34` + #490(영상 칸 문구, 결과에 영향 없음). 주로 데모 흐름(`/`)으로 봤고, 실제 API(`?api`)는 로컬 API 서버로 업로드 · 진행 · 분석 중단 · 설명 고치기까지 봤다.

## 방법

- **자동**: axe-core 4.10.2를 화면마다 돌렸다. Lighthouse 12.8.2(접근성만, headless Chrome)는 첫 화면(업로드)에서 돌렸다 — 다른 화면은 흐름을 거쳐야 해서 axe로만 봤다.
- **확대**: 1280px 화면을 200%로 키운 것과 같은 640px 폭에서 업로드 → 진행 → 신고 상황 확인 → 결과를 봤다.
- **수동**: 키보드만으로 업로드 → 진행 → 신고 상황 확인 → 결과 → 번호판 확인 · 수정 → 뒤로를 끝까지 진행했다(Tab · Shift+Tab · Enter · Space). 운영체제 파일 선택 창만 스크립트로 대신했다.
- **고대비**: headless Chrome에 강제 색상(`forced-colors: active`)을 켜고 업로드 · 진행 · 결과 · 번호판 입력 화면을 찍어 봤다.
- **상태 안내**: 진행 화면의 live 영역 글자가 바뀌는 횟수를 10초 동안 셌다.
- **화면 낭독기**: NVDA 2026.3(휴대용, 무음 음성 · 음성 로그)을 켠 채 Chrome에서 업로드 → 진행 → 신고 상황 확인을 키보드로 진행하고, NVDA가 읽은 내용을 로그로 확인했다.
- **화면**: 정상 흐름과 데모 시나리오 결과 없음 · 장면 찾기 실패 · 분석 중단 · 위반 미관찰 · 번호판 못 읽음 · 신고용 영상 미생성 · 업로드 실패.

| # | 정도 | 어디 | 무엇 | 고치는 방향 |

| 1 | 중 | 진행 화면 `FlowScreen.tsx` (`.flow-head`, `aria-live="polite"`) | 「경과 시간」이 live 영역 안에 있어 1초마다 화면 낭독기가 읽는다. 10초 동안 live 영역 글자가 16번 바뀌었고 그중 다수가 경과 시간만 바뀐 것이었다. NVDA는 「경과 시간 00:01」 「경과 시간 00:02」 …를 1초마다 읽었고 단계 이름(「장면 찾기」 · 「후보 확인」)이 그 사이에 섞였다 | 경과 시간을 live 영역 밖으로 뺀다 |
| 2 | 중 | 화면 전환 전반 | 진행 → 신고 상황 확인, 「맞아요」 → 결과, 번호판 확인 「뒤로」 → 결과, 결과 없음 · 실패 · 중단 · 위반 미관찰로 넘어가면 초점이 `body`로 떨어진다(실제 API의 「분석 중단」 → 중단 화면도 같다). 화면이 바뀐 것을 알 수 없다. ## 한계 — 하지 않은 것

- **화면 낭독기**: NVDA는 업로드 → 진행 → 신고 상황 확인까지만 들었다(음성 로그). 결과 화면 · 후보 시간축(#6)은 접근성 트리로 판단했다. VoiceOver는 보지 않았다.
- **실제 API 결과 화면**: 로컬 API 서버에 Worker가 돌지 않아 첫 작업(`HINT_EXTRACT`)이 대기에 머물렀다. 그래서 실제 API로는 업로드 · 진행 · 분석 중단 · 설명 고치기까지만 봤다(axe 0건, 「설명 고치기」는 제목에 초점이 간다). 신고 상황 확인 · 결과 · 발생 시각 입력은 데모 흐름과 코드로 봤다 — 시각 입력 화면은 날짜 · 시간 칸에 `label`이 있고 열 때 제목에 초점이 가며, 「한국 시간 기준으로 저장해요.」 안내는 칸에 연결돼 있지 않다.
- **고대비**: Windows 고대비 설정이 아니라 Chrome의 강제 색상 흉내로 봤다.
- **Lighthouse**: 첫 화면만. 다른 화면은 흐름을 거쳐야 해서 axe로만 봤다.
- 복사 버튼은 검사 창에 클립보드 권한이 없어 실패 안내만 확인했다.
- A11Y-07(데모 영상 자막)은 영상 몫이라 범위 밖이다.
