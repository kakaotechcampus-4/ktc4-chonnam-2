## 2. 구조 확정에 필요한 실험

### 2.1 요소 분리 비교 (E1)

같은 15영상(위반 12·사건 13, 정상 3)에서 아래 4조건을 **각 2회** 실행한다.

| 조건 | Coarse | Fine | 답하는 질문 |
| --- | --- | --- | --- |
| P0 | Flash v3 | Flash | 기준선 |
| P1 | argon | argon | 향상이 모델 교체 덕분인가 |
| P2 | CV | argon | CV 단독 기여 |
| P3 | CV ∪ argon | argon | 현재 후보 구조 |

- P1이 핵심이다. [CV + argon](cv-coarse-argon-fine-2026-10-23.md) 5단계에서 CV 후보 5건 중 3건(`C05`·`C00`·`C10`)은 argon Coarse도 찾았다. CV만 찾은 사건은 2건(`C09` 9.9초·`C44`)이다.
- P1이 P3와 같은 수준이면 CV 없는 구조가 후보가 된다. CV는 라이선스·실행 환경·challenger 승인 부담이 있다(§5).
- Fine 조건(±3초, 0.5배속, 박스 유무)과 채점 규칙은 [CV + argon](cv-coarse-argon-fine-2026-10-23.md) 5단계와 같게 고정한다.
- 15영상은 CV 개발 표본이므로 E1은 **구조 선택용**이다. 성능 향상 판정에는 쓰지 않는다(§3).
- 예상 비용(추정, 10/23 단가 기준): P1 약 ₩540, P3 약 ₩620, P2 약 ₩80, P0 소액. 1회 약 ₩1,300, 2회 약 ₩2,600. 실행 전 상한을 정해 승인받는다.

### 2.2 Fine 오탐 원인 수정과 회귀 확인 (E2)

[CV + argon](cv-coarse-argon-fine-2026-10-23.md)에서 오탐 원인이 두 가지로 좁혀졌다.

| 원인 | 사례 |
| --- | --- |
| 촬영 차량을 대상으로 잡음 | 정상 `141628` 17.0초 |
| 분기부 안전지대 실선 | 정상 `150504` 5.4·6.5초 (박스 없이도 재현) |

- 원인마다 Fine 지시 한 문장씩 별도 변형으로 만든다. 두 변경을 한 변형에 섞지 않는다.
- 대상: 위 음성 장면 + 기존 양성 5건(`C09` 9.9초·`C00`·`C05`·`C10`·`C44`). 각 3회.
- 통과: 음성 OBSERVED 감소, 양성 OBSERVED 유지. 기준 숫자는 실행 전에 정한다.

### 2.3 실선/점선 판별 검증 (E3)

- [CV + argon](cv-coarse-argon-fine-2026-10-23.md) 4단계의 합법 점선 변경 두 구간(`141956` 10–14초, `141927` 14–18초)은 응답이 "차로 변경 없음"이었다. 실선·점선 판별을 검증한 것이 아니다.
- 먼저 6초 클립에 변경 장면이 담겼는지 프레임으로 확인한다. 담기지 않았으면 구간을 정답지 기준으로 다시 잘라 실행한다.
- 5단계 점선 변경 5건 기각은 긍정적 신호로 함께 기록한다.

### 2.4 운영 조건 측정 (E4)

구조 선택에 필요하지만 측정되지 않은 값이다.

- 5분 영상 기준 end-to-end 지연
- CV 단계의 CPU 처리 시간(Worker 실행 환경 기준)
- 영상 1분당 비용(10/23 추정 약 ₩50)
- 정상 영상 1분당 후보 수

## 3. 성능 향상 확인 실험 (E5)

[CV + argon](cv-coarse-argon-fine-2026-10-23.md) 「성능 향상 판정 기준 (2026-10-25 사전 고정)」을 그대로 따른다. 이 문서는 기준을 바꾸지 않는다.

- 영상: CV 개선·프롬프트 조정에 쓰지 않은 새 위반 영상과 정상 영상
- 비교: CV + argon(또는 E1에서 고른 구조)과 Flash B-split 각 2회
- 채점: 이전 Flash 규칙
- 합격: 검출 사건 수가 회차 평균 2건 이상 많음. 오탐은 기록만

실행 전에 확인·보완할 것:

1. **새 양성 사건 수.** 새 위반이 소수면 "2건 이상"으로 판단할 수 없다. 확보 가능한 사건 수를 먼저 센다. 최소 사건 수는 Owner가 실행 전에 정한다.
2. **정상 영상.** eval 매니페스트의 정상 113클립은 CV 튜닝에 쓰지 않았다. 오탐 측정에 쓴다. 다만 [CV 잔여 작업](cv-remaining-plan-2026-10-11.md)은 "정상 실제 영상 0/113"으로 기록했다. 로컬 확보 여부를 먼저 확인한다.
3. **오탐 상한 (제안, Owner 결정 필요).** 사전 기준은 오탐을 기록만 한다. 실제로 정상 기각이 3/3 → 1/3으로 나빠졌다. 새 결과를 보기 전이라면 "정상 클립 OBSERVED가 비교 조건보다 일정 이상 많으면 보류" 같은 상한을 별도 항목으로 덧붙일 수 있다. 넣을지는 미정이다.
4. **공식 채점 병행.** `eval/scorers/candidate.py`(유형 일치 + 대표 시점 ±2초, Recall@K)로도 계산해 함께 낸다. 09/28 Gemini Coarse 기준(공식 Recall@3 5/10, [#279](https://github.com/kakaotechcampus-4/ktc4-chonnam-2/issues/279) 사전실험 재채점)과 비교할 수 있다.

## 4. 순서

```text
0. #158 합의 요청 재촉 · 새 양성 영상/정답 확보를 eval과 협의 · 정상 113클립 확보 확인
1. E1 요소 분리 (15영상, 2회)       → 구조 후보 1개 선택
2. E2 Fine 오탐 수정 · E3 점선 검증  → 선택 구조의 Fine 지시 확정
3. E4 운영 조건 측정
4. E5 새 영상 성능 판정 (사전 고정 기준)
5. 주간 회의 안건 → 결정 문서 (최종 구조 제안 문서 교체)
```

E1과 E2는 서로 독립이라 병행할 수 있다. E5는 E1·E2가 끝난 구조로 한 번만 실행한다.

- argon 오탐 두 유형은 Fine 문장 한 줄로 이번 표본에서 사라졌다(`ego-v1` 기각, `gore-v1` UNCERTAIN). 양성 보존은 `gore-v1`만 기준을 넘었다.
