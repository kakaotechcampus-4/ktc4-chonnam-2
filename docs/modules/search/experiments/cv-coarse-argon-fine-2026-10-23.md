# CV Coarse 후보 → gemini-4-argon Fine (영상)

실행일: 2026-10-23. 원시 결과·준비 영상·실행 스크립트는 로컬 `.omc/argon-cv-fine-2026-10-23/`, 토큰 측정은 `.omc/argon-token-probe-2026-10-23/`에 둔다(저장소 밖).

## 질문

Coarse를 Gemini 대신 CV 차선 교차 후보([CV 잔여 작업 처리 결과](cv-remaining-plan-2026-10-11.md)의 최신 개발 기준)로 바꾸고, Fine을 새 모델 `gemini-4-argon`에 영상으로 맡기면 **후보를 맞는 차량·유형으로 확인하고 위반이 아닌 구간은 기각하는가.**

## 조건

- 엔드포인트 `mlapi.run` 프록시, 반환 모델 `gemini-4-argon`, `reasoning_effort=low`, 재시도 0, 응답 스키마 `FineResponse`.
- 프록시는 영상을 재생 1fps로 읽는다고 보고, 영상을 0.5배속으로 늘려 원본 2fps를 넣는다. 음성 제외, 원본 해상도(최대 720p).
- 후보: `motion-region-support-2026-10-11/selected-full-run/candidates.json`의 11개. 두 추적기가 같은 사건을 낸 것을 (영상, 교차 시각)으로 합쳐 **고유 6개**(ByteTrack 우선). 위반 유형은 모두 UNKNOWN이다.
- 클립: 교차 시각 ±3초. CV가 추적한 차량 박스(`frames.jsonl`, 5fps)를 빨간 사각형으로 그렸다. 관측이 0.2초 이상 떨어진 프레임에는 그리지 않는다. 호출 전 6개 모두 박스가 의도한 차량에 있는지 중간 프레임으로 확인했다.
- 대상 힌트: "영상에 빨간 사각형으로 표시한 차량. 사각형은 자동 추적 결과라 어긋나거나 잠깐 사라질 수 있다."
- 단가(사용자 제공): 입력 ₩2,835·캐시 ₩141·출력 ₩14,175 / 1M 토큰. 캐시 할인은 적용하지 않은 계산 값이며 청구서 금액이 아니다.

## 한계

- 양성 5·음성 1, 1회다. 검출률·오탐률을 말할 수 없다.
- 빨간 박스가 "의심 차량" 신호로 작용해 OBSERVED 쪽으로 기울게 했을 가능성을 이 표본으로는 구분할 수 없다. 정상 영상 확인이 필요하다(3단계).
- `YT_0003_C05`는 차량이 작아 박스가 차체 일부를 가린다.
- CV가 후보를 내지 못한 정답 6구간은 범위 밖이다. 파이프라인 전체 recall이 아니라 **Fine이 받은 후보를 맞게 판정하는가**만 본다.
- 기존 sol·Flash 실험과 Coarse·모델·전송 방식이 모두 달라 수치를 직접 비교하지 않는다.

## 3단계 · 정상 영상 기각과 유형 제공 (1회)

### 방법

1. **정상 3클립 × 4개 유형 한 번에 (3호출):** set1 정상 `20260620_141628_EVT_1`·`141956_EVT_1`·`150504_EVT_1`. CV 후보가 없으므로 ByteTrack 차선 거리 표본 중 차선에 가장 가까운(|d_px| 최소) 차량 시점을 고른다. 조건은 앞뒤 3초 관측 15개 이상, 3–17초 안이며 API 결과를 보기 전에 고정했다. 결과는 141628 track 40 9.8초, 141956 track 12 14.4초, 150504 track 17 5.4초다. 세 클립 모두 박스가 점선 부근의 원거리 차량에 있음을 확인했다.
2. **유형 제공 1회 (9호출):** 고유 CV 후보 6개와 정상 3클립에 위반 유형 1개를 알려 주는 운영 프롬프트(`fine_prompt_for`)로 1번씩 부른다. 정답 구간 후보는 정답 유형, 그 밖과 정상은 기존 관례대로 `SOLID_LINE_LANE_CHANGE`다. 2단계(4개 한 번에)와 같은 클립으로 비교한다.

사전 통과 기준: 정상 3클립 모두 기각(OBSERVED가 아님, 두 조건 각각), 유형 제공 조건에서 정답 구간 5개 중 4개 이상 OBSERVED. 예상 ₩155·상한 ₩300으로 승인받아 실행했다.

### 해석

- 이 작은 표본에서는 유형을 알려 주든 4개를 한 번에 주든 양성 판정이 같다. 유형 제공의 이점은 확인되지 않았다.
- 점선 변경(`141628`)은 두 조건 모두 정확히 기각했다. 반면 분기부·안전지대처럼 실선과 점선이 섞인 장면에서 OBSERVED가 나왔고, 원거리 차량(`141956`)은 응답마다 서술이 달랐다.
- 정상 기각 2/3은 3클립 1회 결과라 오탐률로 쓰지 않는다.
