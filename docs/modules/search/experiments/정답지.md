# video/ 정답지 (사람 라벨 + 프레임 검증)

`video/` 의 EVT·YouTube 클립에 대한 사람 판정 정답이다. 탐침 결과 비교·recall 측정에 재사용한다.
모델 출력이 아니라 **사람이 원본을 보고 적은 사실**이며, 일부는 Claude 가 프레임을 뽑아 교차검증했다.

- 이벤트 계약명: `SIGNAL`, `CENTER_LINE_CROSSING`, `SOLID_LINE_LANE_CHANGE`, `MOTORCYCLE_HELMET_NON_USE`
- **위반 판정 기준**: 차로변경이 **실선**을 넘으면 `SOLID_LINE_LANE_CHANGE` 위반, **점선**이면 합법(위반 아님). 중앙선 침범은 `CENTER_LINE_CROSSING`으로 기록한다.
- 오프셋은 클립 시작 기준 초(second). ffprobe 실측 길이 병기. `clip_ordinal × 300` 가정 쓰지 말 것.
- `정답 출처`: `user` = 소유자 육안 라벨, `claude_frame` = 1fps 프레임 판독 교차검증.

## 파일별 상세

### `20260620_141628_EVT_1.avi` — 차로변경 없음
- **사람 정답(user): 차선 변경 없음.**
- claude_frame 교차검증(0.0–3.0s): 서해대교형 교량 구간. 앞 검은 싼타페가 우측으로 이동하는 듯 보이나,
  ego 가 우측 차를 추월하며 생긴 원근 이동과 실제 차로변경을 **정지 프레임으로는 구분 불가**.
  횡단 지점 부근 선은 점선이고, 확대에서 보인 실선은 진출부(gore) 가장자리선으로 보인다.
- 참고: 이 클립에서 모델(3.7-flash, tag `allvid`)은 `SOLID_LINE_LANE_CHANGE` **OBSERVED(실선 위반)** 로 과탐했다.
  사람 정답과 불일치 → **모델 오탐(FP) 유력**. 영상 재생으로 최종 확정 권장.

### `20260620_141927_EVT_1.avi` — 실선 차로변경 (위반)
- **사람 정답(user): 차로변경 있음, 구간 t≈4–9s(교량부).** 선종류 확인 요청 → claude_frame 으로 확인.
- claude_frame 확인: 교량(서해대교) 구간에서 앞 회색 SUV 가 ego 우측 **백색 실선**을 넘어 우측 차로로 변경.
  확대 프레임에서 해당 선이 끊김 없는 연속 실선임을 확인 → **실선 위반 확정.** (구간은 사람 정답 4–9s 채택)
- 별건: 교량 이후 **t≈14–18s** 에 같은 SUV 가 **점선** 구간에서 한 번 더 우측 변경(합법).
  이 영상엔 차로변경이 **2회**(실선 1 + 점선 1) 있다.
- 참고: 모델(tag `allvid`)은 Coarse 가 구간을 t14–18.5s(점선 건)로 잡아 Fine 이 `NOT_OBSERVED` 를 냈다.
  즉 **실제 위반(실선, 교량부)을 놓침 → 모델 미검출(FN)**. Fine 판별 자체가 아니라 Coarse 구간 국소화가 원인.

- **사람 정답(user): t≈10–14s 점선 차로변경.** 점선이므로 위반 아님 → 정답 판정은 `NOT_OBSERVED`.

  Coarse recall 이 회차마다 흔들림.
