# 대신고 데모 시나리오

2026-11-04 · 김대원 · 금요일 회의 소개용 초안

## 개요

데모 영상은 두 편이다. 같은 블랙박스 폴더와 같은 사건을 쓰지만 목적이 다르다.

- **100초 발표용(발표자료에 넣는 영상):** 앞부분은 직접 신고, 뒷부분은 대신고로 같은 사건을 신고한다. 끝에 걸린 시간을 비교한다.
- **5분 이내 제출용:** 직접 신고는 넣지 않는다. 대신고가 단계마다 무엇을 하는지, 값이 확실하지 않거나 장면을 찾지 못하는 상황까지 차근차근 설명한다. 5분을 다 채우지 않아도 된다(현재 약 4분 30초).
- **샘플 영상:** `블랙박스_데모` 폴더(1분 파일 8개, 약 15분). 사건은 `20261026_161705_F.mp4`의 30–36초에 있다. 앞에 가던 은색 SUV가 노란 중앙선을 넘어 왼쪽 골목으로 들어간다.
- **번호판:** 사건 차량에는 합성한 가짜 번호판 `157가 2846`을 넣었다. 주변 차량 번호판은 실제 번호판이다.
- **로컬 확인 결과(11/3):** 사건 파일 1개를 올리면 1순위 후보가 사건 장면(32.5초)이다. 위반 유형은 중앙선 침범, 번호판은 `157가2846`으로 읽혔다. 분석은 약 4분 걸렸다.

## 100초 발표용 시나리오

**같은 사건을 먼저 직접 신고하고, 이어서 대신고로 신고한다.** 서비스 설명은 발표자가 말로 하므로 영상은 차이만 보여 준다. 화면 오른쪽 위에 타이머를 띄운다. 타이머는 실측값이고, 줄인 구간에는 「배속」 또는 「대기 구간 단축」을 표시한다. ○는 촬영 후 실측값으로 채운다.

### #1 0–5초 같은 사건

- **화면:** 사건 장면(`161705` 30–36초)을 전체 화면으로 보여 준다. 이어서 파일 8개가 든 블랙박스 폴더로 넘어간다.
- **나레이션:** "같은 사건을 두 번 신고해 봤습니다. 먼저 직접 해 보겠습니다."
- **자막:** 「블랙박스 영상 8개 · 약 15분」

### #2 5–40초 직접 신고

- **화면:** 직접 신고 녹화를 배속으로 이어 붙인다. 타이머가 계속 올라간다.
    1. 파일을 하나씩 열어 빨리감기로 장면 찾기
    2. 안전신문고에 첨부했다가 130MB 초과 오류
    3. 편집기로 사건 구간 자르기
    4. 영상을 멈추고 번호판 확대해 읽기
    5. 주소·제목·내용·일시를 손으로 입력하고 「신청」 직전에서 멈춤
- **나레이션:** "파일을 하나씩 열어 장면을 찾고, 용량에 맞게 자르고, 번호판을 읽고, 신고서를 손으로 씁니다."
- **자막:** 단계 이름 ①–⑤, 「배속」, 마지막에 「직접 신고 ○○분」을 크게 멈춰 둔다.

### #3 40–45초 전환

- **화면:** 「이번엔 대신고로」 카드. 타이머가 00:00으로 돌아간다.
- **나레이션:** "이번엔 대신고로 해 보겠습니다."
- **자막:** 「같은 영상 · 같은 사건」

### #4 45–65초 올리고 한 줄 적기

- **화면:** 대신고 홈에 영상을 끌어다 놓는다. 상황 칸에 "앞에 가던 SUV가 중앙선을 넘어서 왼쪽 골목으로 들어갔어요"를 적고 분석을 시작한다. 진행 화면은 빨리 넘긴다.
- **나레이션:** "영상을 올리고 기억나는 대로 한 줄만 적으면, 장면 찾기부터 번호판 읽기까지 대신고가 합니다."
- **자막:** 「대기 구간 단축 · 실제 분석 ○분 ○초」

### #5 65–88초 확인하고 붙여넣기

- **화면:**
    1. 결과 화면에 사건 구간, 중앙선 침범, `157가 2846`, 발생시각이 채워져 있다.
    2. 번호판을 한 번 확인하고 신고 상황에 응답한다.
    3. 신고내용 복사 → 신고용 영상 다운로드 → 안전신문고에 붙여넣기·첨부 → 「신청」 직전에서 타이머가 멈춘다.
- **나레이션:** "사용자는 확인하고, 붙여 넣고, 제출만 합니다."
- **자막:** 「대신고 ○분」, 「번호판은 데모용 합성 번호판」

### #6 88–100초 시간 비교

- **화면:** 두 타이머를 나란히 놓은 끝 카드. 「직접 ○○분 → 대신고 ○분」
- **나레이션:** "영상을 뒤지고 편집하던 일을, 대신고가 대신합니다."
- **자막:** 「같은 영상 · 같은 사건 · 실측 시간」, 「사건 차량 번호판은 합성」

## 5분 이내 제출용 시나리오

**대신고 서비스만 보여 준다.** 직접 신고 장면은 넣지 않는다. 세 부분으로 나눠 차근차근 설명한다.

1. **기본 흐름(#1–#8):** 영상 올리기부터 안전신문고까지, 단계마다 「대신고가 하는 일 / 사용자가 하는 일」.
2. **값이 확실하지 않을 때(#4–#6 안의 「다른 상황」):** 번호판·시각·위치를 읽지 못했을 때 화면이 어떻게 달라지는지.
3. **찾지 못하거나 실패했을 때(#9–#10):** 원하는 장면이 아닐 때, 장면이 없을 때, 시스템 문제가 생겼을 때의 출구.

화면 문구는 현재 웹 앱 문구를 그대로 적었다. 「다른 상황」 화면은 기본 촬영본으로는 나오지 않으므로 따로 찍는다(아래 「촬영 준비물」). ○는 촬영 후 실측값으로 채운다.

### #1 0:00–0:20 대신고 소개

- **화면:** 사건 장면(`161705` 30–36초)을 3초 보여 준 뒤 설명 카드로 넘어간다. 카드 왼쪽은 「사용자가 하는 일」(영상 올리기, 한 줄 적기, 확인·응답, 제출)이다. 오른쪽은 「대신고가 하는 일」(장면 찾기, 위반 확인, 번호판·시각 읽기, 신고용 영상 만들기, 신고문 쓰기)이다.
- **나레이션:** "대신고는 블랙박스 영상에서 교통위반 신고 자료를 준비해 주는 서비스입니다. 시간이 오래 걸리는 일은 대신고가 하고, 사용자는 확인하고 제출합니다."
- **자막:** 「보고, 고르고, 제출만 하세요」

### #2 0:20–0:50 영상 올리기와 한 줄 단서

- **화면:** 대신고 홈에 폴더의 영상을 끌어다 놓는다. 파일 목록이 시간 순서로 정리된다. 상황 칸에 "앞에 가던 SUV가 중앙선을 넘어서 왼쪽 골목으로 들어갔어요"를 적고 분석을 시작한다.
- **나레이션:** "블랙박스 영상을 그대로 올립니다. 대신고는 파일 이름과 화면 시각으로 영상의 순서를 맞춥니다. 그리고 기억나는 대로 한 줄만 적습니다. 정확한 시각을 몰라도 괜찮습니다. 이 한 줄에서 차량, 상황, 위치 단서를 뽑아 장면을 찾습니다."
- **자막:** 「단서: SUV · 중앙선 넘음 · 왼쪽 골목」
- **다른 상황 (자막으로만):** 한 번에 볼 수 있는 길이를 넘으면 「영상이 너무 길어 한 번에 살펴볼 수 없어요. 사건 장면이 담긴 영상만 골라 다시 올려 주세요.」가 나온다.

### #3 0:50–1:20 AI 분석 진행

- **화면:** 진행 화면에서 단계가 차례로 넘어간다. 후보 찾기 → 유력 후보 위반 확인 → 번호판·시각 읽기 → 신고용 영상 준비. 끝난 단계는 초록색 완료 표시로 남는다. 기다리는 구간은 빨리 넘긴다. 중간에 「두 단계 탐색」 그림 카드를 3초 넣는다. 「분석 중단」 버튼을 가리킨다.
- **나레이션:** "대신고는 두 단계로 찾습니다. 먼저 전체 영상을 훑어 설명과 맞는 장면 후보를 고릅니다. 그다음 가장 유력한 후보를 자세히 봐서 실제로 위반이 일어났는지 확인합니다. 사용자는 누를 것이 없습니다. 언제든 분석을 멈출 수 있고, 멈추는 것은 실패가 아니라 사용자의 선택으로 기록됩니다."
- **자막:** 카드 「① 넓게 훑기 → ② 자세히 확인하기」, 「대기 구간 단축 · 실제 분석 ○분 ○초」

### #4 1:20–2:00 결과 화면과 정보 상태, 번호판

- **화면:** 결과 화면이 열린다. 사건 구간(약 32초)을 재생하면 SUV가 중앙선을 넘는다. 「정보 상태」 설명 카드를 3초 넣는다(AI 추정 · 출처 확인됨 · 사용자 확인됨 · 확인 필요 · 알 수 없음). 이어서 차량번호 `157가 2846`을 확대하고 「확인·수정하기」로 번호판 장면을 연다. 확인하면 상태가 「사용자 확인됨」으로 바뀐다.
- **나레이션:** "가장 유력한 후보로 신고 자료 초안이 바로 준비됩니다. 대신고는 값마다 어디서 왔는지, 얼마나 확실한지를 함께 보여 줍니다. 번호판은 영상에서 직접 읽었고, 사용자가 장면을 보고 확인하면 확인된 값이 됩니다."
- **자막:** 상태 이름 강조, 「번호판은 데모용 합성 번호판」
- **다른 상황 (추가 촬영):** 번호판을 확정하지 못하면 값을 지어내지 않고 「알 수 없음」으로 둔다. 「번호판 직접 입력」 버튼이 나오고, 번호판 없이도 신고 자료는 끝까지 준비된다.
    - **나레이션:** "번호판을 확실히 읽지 못하면 값을 지어내지 않습니다. 비워 두고 알려 주며, 직접 입력할 수 있습니다."

### #5 2:00–2:25 발생시각

- **화면:** 발생시각 값과 출처 「영상 화면에 표시된 시각」을 확대한다.

- **화면 (추가 촬영):** 고른 장면에서 위반이 보이지 않으면 「이 장면에서는 신고할 위반을 확인하지 못했어요.」와 「설명 고치기」가 나온다.
- **나레이션:** "원하는 장면이 아니면 다른 후보를 고를 수 있습니다. 새 후보에 맞는 값만 다시 준비합니다. 위반이 보이지 않는 장면은 억지로 신고 자료를 만들지 않고, 설명을 고쳐 다시 찾게 합니다."
- **자막:** 「새 후보 기준으로 다시 준비」

### #10 4:00–4:20 찾지 못했거나 문제가 생겼을 때 (추가 촬영)

- **화면:** 두 화면을 차례로 보여 준다.
    1. 사건과 맞지 않는 설명으로 찾았을 때: 「말씀하신 장면을 찾지 못했어요.」와 「어떤 장면이었는지 조금만 더 알려 주세요」 입력 칸.
    2. 시스템 문제가 생겼을 때: 「장면을 찾는 중에 문제가 생겼어요.」, 「지금까지 끝난 작업은 저장돼 있어요. 다시 시도하면 멈춘 곳부터 이어서 할게요.」와 「다시 찾기」.
- **나레이션:** "장면을 찾지 못하면 그렇다고 말하고, 무엇을 더 알려 주면 되는지 묻습니다. 시스템 문제는 '찾지 못함'과 구분해서 알리고, 끝난 작업은 저장해 둔 채 이어서 할 수 있게 합니다."
- **자막:** 「찾지 못함 ≠ 시스템 문제」

## 주의사항과 금요일에 정할 것

촬영 전에 배포본에서 확인해야 할 문제가 두 가지 있다. 두 편 모두 결과 화면 장면이 여기에 달려 있다.

- **발생시각이 12시간 틀린다.** 영상 화면의 `04:17:34PM`을 오후로 읽지 못해 04:17로 나온다. 시각 읽기(readout) 담당에게 이슈를 올려야 한다. 고쳐지지 않으면 5분 #5와 100초 #5에서 시각 값을 보여 주는 장면을 빼야 한다.
- **여러 파일을 함께 올리면 로컬에서 실패했다.** 파일 3개(약 3.9분)가 후보 찾기 단계에서 멈췄다. 원인은 아직 모른다. 배포본에서도 안 되면 사건 파일 1개만 올리는 장면으로 찍는다.
- **폴더 전체(약 15분)는 분석 길이 상한을 넘는다.** 배포본 상한은 약 9분 이하로 기록돼 있다(#452). 화면에는 폴더 전체를 보여 주되, 실제로는 사건 전후 파일만 올린다.
- **번호판 고지.** 사건 차량 번호판 `157가 2846`은 합성이다. 두 편 모두 자막으로 밝힌다. 주변 차량의 실제 번호판은 편집할 때 흐림 처리한다.
