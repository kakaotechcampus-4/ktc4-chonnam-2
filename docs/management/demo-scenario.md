# 대신고 데모 시나리오

2026-11-04 · 김대원 · 금요일 회의 소개용 초안

## 개요

데모는 **같은 블랙박스 폴더로 직접 신고와 대신고 신고를 나란히 보여 주고, 걸린 시간을 비교**한다. 핵심 메시지는 「영상을 뒤지고, 자르고, 번호판을 읽던 일을 대신고가 대신한다」이다.

- **영상 두 개:** 5분 제출용(서비스 설명)과 100초 발표용(직접 신고와 비교)이다. 촬영은 한 번 하고, 두 편을 따로 편집한다.
- **구성 원칙:** 100초는 기존 Figma 콘티(10/28)의 장면 순서를 따른다. 5분은 서비스 설명 중심으로 새로 짰다. 샘플 영상은 두 편 모두 아래 영상으로 바꾼다.
- **샘플 영상:** `블랙박스_데모` 폴더(1분 파일 8개, 약 15분). 사건은 `20261026_161705_F.mp4`의 30–36초에 있다. 앞에 가던 은색 SUV가 노란 중앙선을 넘어 왼쪽 골목으로 들어간다.
- **번호판:** 사건 차량에는 합성한 가짜 번호판 `157가 2846`을 넣었다. 주변 차량 번호판은 실제 번호판이다.
- **로컬 확인 결과(11/3):** 사건 파일 1개를 올리면 1순위 후보가 사건 장면(32.5초)이다. 위반 유형은 중앙선 침범, 번호판은 `157가2846`으로 읽혔다. 분석은 약 4분 걸렸다.

## 두 편의 차이

두 편은 같은 촬영본을 쓰지만 **목적과 구성이 다르다.** 5분은 서비스가 무엇을 어떻게 하는지 설명한다. 100초는 직접 신고와 나란히 붙여 차이를 보여 준다.

| | 5분 (제출용) | 100초 (발표용) |
| --- | --- | --- |
| 보는 사람 | 영상만 보는 심사위원 | 발표를 듣는 청중 |
| 핵심 | 서비스 설명: 단계별로 AI가 하는 일과 사용자가 하는 일 | 비교: 같은 사건, 걸리는 시간의 차이 |
| 화면 | 대신고 전체 화면 + 설명 카드. 직접 신고는 앞부분 40초 요약만 | 좌우 분할(왼쪽 직접 · 오른쪽 대신고), 두 타이머 동시 진행 |
| 나레이션 | 장면마다 설명하는 문장 | 짧게, 장면당 한 문장 |

## 5분 제출용 시나리오

**대신고가 신고 과정의 각 단계에서 무엇을 대신 하는지 설명하는 영상이다.** 직접 신고는 앞부분에 요약으로만 보여 준다. 나머지는 대신고 화면을 따라가며 단계마다 「AI가 하는 일 / 사용자가 하는 일」을 설명한다. ○는 촬영 후 실측값으로 채운다.

### #1 0:00–0:20 문제 제기

- **화면:** 블랙박스 사건 장면(`161705` 30–36초)을 전체 화면으로 보여 준다. 이어서 파일 8개가 든 블랙박스 폴더로 넘어간다.
- **나레이션:** "앞차가 중앙선을 넘어 골목으로 들어갔습니다. 블랙박스에는 찍혔지만, 실제로 신고하는 사람은 많지 않습니다. 신고까지 가는 길이 너무 길기 때문입니다."
- **자막:** 「블랙박스 영상 8개 · 약 15분」

### #2 0:20–1:00 직접 신고는 어떤가 (요약)

- **화면:** 직접 신고 녹화를 빨리 이어 붙인다.
    1. 파일을 하나씩 열어 장면 찾기
    2. 안전신문고 첨부 시 130MB 초과 오류
    3. 편집기로 구간 자르기
    4. 영상을 멈춰 번호판 확대
    5. 주소·제목·내용·일시 직접 입력

    화면 구석에 실제 경과 시간이 올라간다.
- **나레이션:** "직접 신고하려면 파일을 하나씩 열어 장면을 찾고, 용량에 맞게 영상을 자르고, 번호판을 확대해 읽고, 신고서를 손으로 채워야 합니다. 이번 사건에는 ○○분이 걸렸습니다."

### #3 1:00–1:20 대신고 소개

- **화면:** 설명 카드. 왼쪽에 「사용자가 하는 일」(영상 올리기, 한 줄 적기, 확인, 제출)을 둔다. 오른쪽에 「대신고가 하는 일」(장면 찾기, 위반 확인, 번호판·시각 읽기, 영상 자르기, 신고문 쓰기)을 나란히 놓는다.
- **나레이션:** "대신고는 블랙박스 영상에서 교통위반 신고 자료를 준비해 주는 서비스입니다. 사람이 하던 일 중 시간이 걸리는 일은 대신고가 하고, 사용자는 확인하고 제출만 합니다."
- **자막:** 카드 제목 「보고, 고르고, 제출만 하세요」

### #4 1:20–1:50 영상 올리기와 기억 단서

- **화면:** 대신고 홈에 폴더의 영상을 끌어다 놓는다. 상황 칸에 "앞에 가던 SUV가 중앙선을 넘어서 왼쪽 골목으로 들어갔어요"를 적고 분석을 시작한다.
- **나레이션:** "영상을 올리고 기억나는 대로 한 줄만 적습니다. 정확한 시각을 몰라도 괜찮습니다. 대신고는 이 한 줄에서 차량, 상황, 위치 단서를 뽑습니다. 파일 이름과 화면 시각으로 영상의 순서도 맞춥니다."

- **화면:** 결과 화면이 열린다. 사건 구간(약 32초)을 재생하면 SUV가 중앙선을 넘는다. 이어서 값을 하나씩 확대한다.

## 100초 발표용 시나리오

**화면을 좌우로 나눠 같은 사건을 직접 신고(왼쪽)와 대신고(오른쪽)로 동시에 진행한다.** 서비스 설명은 발표자가 말로 하므로, 영상은 차이만 보여 준다. 각 쪽 위에 타이머를 띄운다. 그 장면에서 강조하지 않는 쪽은 흐리게(40%) 처리한다.

### #1 0–8초 같은 폴더에서 시작

- **화면:** 양쪽 모두 같은 블랙박스 폴더(파일 8개). 두 타이머가 동시에 시작한다.
- **나레이션:** "같은 영상, 같은 사건. 신고를 끝내는 데 얼마나 걸릴까요?"
- **자막:** 왼쪽 「직접」, 오른쪽 「대신고」, 타이머 「00:00」

### #2 8–30초 장면 찾기

- **화면:** 왼쪽은 파일을 하나씩 열어 빨리감기한다(배속). 오른쪽은 영상을 끌어다 놓고 "앞에 가던 SUV가 중앙선을 넘어서 왼쪽 골목으로 들어갔어요"를 적은 뒤 분석을 시작한다.
- **나레이션:** "직접 찾으면 파일을 하나씩 열어야 합니다. 대신고는 기억나는 대로 한 줄이면 됩니다."
- **자막:** 왼쪽 「배속 · 실제 ○분」, 오른쪽 「자동 진행」
- **강조:** 앞부분은 왼쪽, 뒷부분은 오른쪽

### #3 30–55초 자르고 읽기 vs 확인만

- **화면:** 왼쪽은 130MB 초과 오류 → 편집기로 구간 자르기 → 번호판 확대. 오른쪽은 결과 화면에 사건 구간, 중앙선 침범, `157가 2846`, 발생시각이 채워져 있다. 번호판을 한 번 확인한다.
- **나레이션:** "찾고, 자르고, 번호판을 읽는 일은 대신고가 합니다. 사용자는 확인만 합니다."
- **자막:** 오른쪽 「사용자 확인」, 「대기 구간 단축 · 실제 분석 ○분 ○초」, 「번호판은 데모용 합성 번호판」
- **강조:** 오른쪽

### #4 55–80초 안전신문고 신고

- **화면:** 왼쪽은 주소·제목·내용·일시를 직접 입력하는 중이다. 오른쪽은 신고내용 복사 → 영상 다운로드 → 안전신문고에 붙여넣기·첨부 → 「신청」 직전. 오른쪽 타이머가 먼저 멈춘다.
- **나레이션:** "준비된 자료를 붙여 넣으면 신고가 끝납니다."
- **자막:** 오른쪽 「신고 준비 완료 · ○분」
- **강조:** 오른쪽. 왼쪽은 아직 입력 중인 것이 보여야 한다.

### #5 80–95초 직접 쪽도 완료

- **화면:** 왼쪽이 뒤늦게 「신청」 직전에 도착하고 타이머가 멈춘다. 두 타이머가 나란히 남는다.
- **나레이션:** 없음
- **자막:** 왼쪽 「신고 준비 완료 · ○○분」

### #6 95–100초 끝 카드

- **화면:** 전체 화면 끝 카드. 「직접 ○○분 → 대신고 ○분」
- **나레이션:** "영상을 뒤지고 편집하던 일을, 대신고가 대신합니다."

## 촬영 준비물

촬영은 한 번 하고, 그 녹화로 두 편을 편집한다.

| 항목 | 내용 | 상태 |
| --- | --- | --- |
| 샘플 영상 | `Desktop\블랙박스_데모` 8개(1080p, 약 15분). 사건은 `20261026_161705_F.mp4` 30–36초 | 준비됨 |
| 대신고 화면 | 동결 버전(RC) 실제 배포본으로 촬영한다. 프로토타입 녹화는 쓰지 않는다 | 로컬에서만 확인 |
| 직접 신고 녹화 | 새 샘플 영상으로 다시 찍는다. 10/28 녹화는 다른 영상이라 쓸 수 없다 | 다시 찍어야 함 |
| 타이머 | 두 쪽 모두 최종 촬영의 실측값만 쓴다. 줄인 구간에는 「대기 구간 단축 / 실제 ○분」을 표시한다 | 촬영 후 |
| 설명 카드 (5분 #3, #5) | 「사용자가 하는 일 / 대신고가 하는 일」, 「넓게 훑기 → 자세히 확인하기」 카드 2장 | 만들어야 함 |
| 나레이션 | 위 문장 그대로 녹음 | 담당 미정 |

녹화 전에 다운로드 폴더를 정리해 비공개 파일명이 첨부 창에 찍히지 않게 한다. 안전신문고에서는 「신청」을 누르지 않는다. 휴대전화 인증과 개인정보 칸은 비워 둔다.

## 주의사항과 금요일에 정할 것

촬영 전에 배포본에서 확인해야 할 문제가 두 가지 있다. 두 편 모두 결과 화면 장면이 여기에 달려 있다.

- **발생시각이 12시간 틀린다.** 영상 화면의 `04:17:34PM`을 오후로 읽지 못해 04:17로 나온다. 시각 읽기(readout) 담당에게 이슈를 올려야 한다. 고쳐지지 않으면 5분 #6에서 시각 값을 보여 주는 장면을 빼야 한다.
- **여러 파일을 함께 올리면 로컬에서 실패했다.** 파일 3개(약 3.9분)가 후보 찾기 단계에서 멈췄다. 원인은 아직 모른다. 배포본에서도 안 되면 사건 파일 1개만 올리는 장면으로 찍는다.
- **폴더 전체(약 15분)는 분석 길이 상한을 넘는다.** 배포본 상한은 약 9분 이하로 기록돼 있다(#452). 화면에는 폴더 전체를 보여 주되, 실제로는 사건 전후 파일만 올린다.
- **번호판 고지.** 사건 차량 번호판 `157가 2846`은 합성이다. 두 편 모두 자막으로 밝힌다. 주변 차량의 실제 번호판은 편집할 때 흐림 처리한다.

금요일에 정할 것:

- [ ] 촬영일과 담당(직접 신고 녹화, 대신고 녹화, 편집)
- [ ] 나레이션 녹음 방식: 사람 목소리인가, 자막만 쓸 것인가
- [ ] 대신고에 올릴 파일 수: 사건 파일 1개인가, 전후 포함 3개인가
- [ ] 5분 #6에서 발생시각 장면을 어떻게 할지(버그 수정 일정에 따라)
- [ ] 사건 장소의 실제 주소(안전신문고 위치 선택에 필요)
