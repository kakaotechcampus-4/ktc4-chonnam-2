# contract ADR

상위 폴더의 Final Data Contract가 **왜 그렇게 확정됐는지**를 남긴다. 계약 1건 = ADR 1건 = 같은 슬러그.

- 계약의 현재 규칙은 상위 폴더의 `contract-<slug>.md`가 소유한다. ADR은 그 결정의 근거·기각안·Consumer Review 기록이다.
- **수락된 ADR의 본문은 고치지 않는다.** 결정이 바뀌면 새 ADR을 쓴다.
- 예외는 **표기 보정** 하나뿐이다 — 같은 결정을 가리키는 식별자가 상위 문서(v4 §5-1 등)와 어긋났을 때. 이때도 두 가지를 지킨다: ① `Status` 바로 아래에 무엇을 왜 고쳤는지 고지를 남긴다 ② 「결정 내용은 바뀌지 않았다」가 사실일 때만 한다. 판단이 서지 않으면 새 ADR을 쓴다.
- ADR 본문에 계약 스키마를 다시 적어 두 곳에서 관리하지 않는다.
- 계약 번호(현재 ①~⑬)와 공통 enum 값 이름은 `architecture/module-architecture.md`가 소유한다. ADR이 그와 다른 이름을 쓰고 있으면 표기 보정 대상이다.
